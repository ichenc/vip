## 使用方式

### 普通用户

1. 访问官网首页：https://vip.212001.xyz/
2. 点击导航栏「一键解析」，将按钮拖拽到浏览器书签栏
3. 在任意视频网站播放页，点击书签栏的「一键解析」即可

### 安装油猴脚本

1. 先安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击首页导航「Web」安装脚本
3. 打开任意视频网站，脚本会自动生效
